# 短牌大菠萝(Short-deck Pineapple)双人热座游戏规则

## 一、游戏配件
- 共 **36张** 数字卡牌。
- 数字为 **6、7、8、9、10、11、12、13、14**（共9种）。
- 颜色为 **红、黄、蓝、绿**（共4种），每种数字与颜色的组合各一张。
- 视觉样式：
  - 红色牌：浅红底，黑色数字。
  - 黄色牌：浅黄底，黑色数字。
  - 蓝色牌：深蓝底，白色数字。
  - 绿色牌：深绿底，白色数字。
  - 数字10~14的字体略小于6~9。

## 二、游戏目标
完整游戏共进行 **6局**。  
每局双方各自获得“大分”，6局结束后比较总大分，高者获胜；若总大分相同则为平局。

## 三、先后手顺序
- 第1、3、5局：玩家1先手，玩家2后手。
- 第2、4、6局：玩家2先手，玩家1后手。
- 特殊情况下会触发“额外局”（详见后文），额外局不计入这6局。

## 四、放牌区域
每位玩家有一个3行放牌区：
- 第一行：**3个格子**
- 第二行：**5个格子**
- 第三行：**5个格子**

所有放下的牌均为明置，对方可见。

## 五、正常局流程
1. 洗匀36张牌，形成牌堆。
2. **先手发5张**：先手玩家必须将这5张牌全部放入自己的空格，然后确认。
3. **后手发5张**：后手玩家同样将5张牌全部放入空格，确认。
4. 随后重复 **4轮** 以下步骤：
   - 先手发3张牌，从中选择 **2张** 放入空格，另外1张弃掉（弃牌不显示）。
   - 后手发3张牌，从中选择 **2张** 放入空格，另外1张弃掉。
5. 一局总共使用34张牌（剩余2张未用），双方棋盘均放置满13张后进入结算。

## 六、牌型与大小

### 1. 三张牌型（用于第一行）
- **三条**：三张数字相同。
- **单对**：两张数字相同，另一张不同。
- **散牌**：三张数字均不同。

**大小**：三条 > 单对 > 散牌。同牌型比较数字大小（单对先比对子，再比单牌；散牌先比最大牌，再比次大牌，再比小牌）。颜色不影响大小。

### 2. 五张牌型（用于第二、三行）
按从大到小排列：
1. **同花顺**：颜色相同且数字连续的五张（14可视为5，即14-6-7-8-9是最小的顺子）。
2. **四条**：四张数字相同。
3. **同花**：颜色相同的五张，但非同花顺。
4. **葫芦**：三张同数字+两张同数字。
5. **顺子**：数字连续的五张，非同花顺（14可视为5，最小为14-6-7-8-9）。
6. **三条**：三张同数字，另有两张不同数字。
7. **两对**：两个不同的对子+一张单牌。
8. **单对**：一个对子+三张不同数字。
9. **散牌**：不构成以上任何牌型。

**特别提醒**：本游戏中 **同花 > 葫芦**，与常见扑克规则不同。  
同牌型比较：优先比较主要部分（例如葫芦先比三条部分，两对先比大对再比小对，最后比单张）。颜色除判断同花顺、同花外无影响。

### 3. 五张牌与三张牌的比较
若一方某行为5张牌，另一方为3张牌（仅第一行为3张，第二、三行均为5张，故正常不会直接比较，但结算时会出现3张与5张比较的情况）。  
此时，3张牌视为额外带上了两张“特别小的、不构成顺子和同花的单牌”，即等同于5张牌参与比较。

## 七、爆牌规则
每位玩家必须满足：
- **第一行 < 第二行 ≤ 第三行**（按牌型大小比较）。

若不满足，则视为“爆牌”。  
爆牌的玩家：
- 该玩家所有牌型无效，视为小于一切有效牌型。
- 该玩家所有小分计为0。
- 双方都爆牌时，双方都不得分。

## 八、局内计分（小分）

### 1. 牌型分（按行计算）
**第一行（3张）**：
- 散牌：0分
- 单对：对子数字 - 5（例如对14得9分）
- 三条：数字 + 8（例如三条6得14分）

**第二行（5张）**：
- 两对及以下：0分
- 三条：2分
- 顺子：4分
- 葫芦：8分
- 同花：12分
- 四条：20分
- 同花顺：30分（若由14-13-12-11-10构成，则计50分）

**第三行（5张）**：
- 三条及以下：0分
- 顺子：2分
- 葫芦：4分
- 同花：6分
- 四条：10分
- 同花顺：15分（若由14-13-12-11-10构成，则计25分）

### 2. 比大小得分
双方对应行（第一行对第一行，第二行对第二行，第三行对第三行）比较牌型大小：
- 较大方额外得 **1小分**。
- 平局或较小方不得分。

### 3. 通杀奖励
若一方三行全部胜出（未爆牌），额外再得 **3小分**。

### 4. 小分折算大分
每局结束，将小分折算为大分：
- **大分 = (小分 + 2) ÷ 5 后向下取整**，即四舍五入效果。

## 九、特殊牌型与额外局

### 1. 特殊牌型状态
- **触发条件**：在正常牌型状态下，第一行构成 **一对14** 或 **三条**，且未爆牌。
- **保持条件**：在特殊牌型状态下，第一行构成 **三条**，或第三行构成 **四条** 或 **同花顺**，且未爆牌。
- 若在特殊状态下未满足保持条件，则回归正常状态。

### 2. 额外局触发
若一方或双方在某局结束后达成（或保持）特殊牌型，则触发 **额外局**。  
额外局不计入6个正常局，每触发一次就多进行一局。

### 3. 额外局先后手
- 仅一方特殊：特殊牌型方为 **后手**。
- 双方特殊：先后手与该额外局之前最近一次正常局相同。

### 4. 额外局流程
- **仅一方特殊**：
  1. 洗牌后，先手按照正常流程进行：发5选5 → 发3选2 × 4轮（共放置13张）。
  2. 后手直接发 **14张牌**，从中选择 **13张** 放入棋盘并确认。
- **双方特殊**：
  1. 先手发14选13，确认。
  2. 后手发14选13，确认。

### 5. 额外局结算与继续
额外局计分规则与正常局完全相同。  
额外局结束后，再次判断双方是否满足特殊牌型条件。  
- 只要有一方仍处于特殊状态，就继续触发新的额外局。
- 双方都未达成特殊状态时，整个游戏流程结束。

## 十、终局判定
6个正常局及所有额外局全部结束后，比较双方的总大分：
- 总大分高者获胜。
- 总大分相同则为平局。

## 十一、界面提示
- 玩家1区域始终在左，玩家2区域始终在右。
- 顶部常驻显示双方总大分、当前局数（额外局显示“第X局 第Y额外局”）。
- 轮到某方决策时，显示明确横幅提示。
- 结算时展示双方详细牌型、各行得分、比大小得分；若出现爆牌、通杀、达成特殊牌型，会有相应特效。
- 确认结算后，可手动点击“继续下一局”或“继续额外局”进入后续游戏。
